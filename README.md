# Budget Tracker

A personal finance management app built with Angular 18 and a Node.js REST backend. Track income, expenses, and monthly budgets with a clean, responsive UI.

## Tech stack

- **Frontend:** Angular 18, TypeScript, SCSS, Angular Material
- **Backend:** Node.js, Express (see [budget-tracker-backend](https://github.com/simisebastian/budget-tracker-backend))
- **Architecture:** Standalone components, reactive forms, HttpClient

## Features

- Add, edit, and delete income and expense entries
- Category-based expense grouping
- Monthly summary view
- Responsive layout for mobile and desktop

## Getting started

```bash
git clone https://github.com/simisebastian/budget-tracker
cd budget-tracker
npm install
ng serve
```

Navigate to `http://localhost:4200`
